# shaderbox-mocks

Rendered design mocks for ShaderBox, published so they can be read from a phone.

Each mock is a static HTML page with no build step and no dependencies. The
source of truth for every mock is the ShaderBox repository itself, under
`ai_docs/features/`; this repository holds only the rendered copy.

Live: https://alexeykarnachev.github.io/shaderbox-mocks/
